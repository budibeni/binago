# ADATRACK - Database Design

## Status

Database production **belum menjadi scope frontend Task saat ini**.

## Prinsip

Dokumen ini menjadi placeholder architecture untuk tahap backend/database berikutnya.

Frontend menggunakan dummy data dan tidak memerlukan database.

## Aturan Masa Depan

Ketika database mulai dikerjakan:

- schema harus terdokumentasi
- naming internal menggunakan English
- migration harus terkontrol
- business rule harus berasal dari requirement yang disepakati

Jangan membuat schema production selama Task frontend hanya karena membutuhkan dummy data.
