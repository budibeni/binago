# BINAGO — Project Overview

## 1. Gambaran Umum

BINAGO adalah platform yang memiliki dua application terpisah:

- BINAGO Business
- BINAGO Personal

Pengembangan saat ini berfokus pada frontend.

## 2. Scope Pengembangan Saat Ini

Frontend dikerjakan menggunakan dummy/mock data.

Fokus:

- UI
- UX
- Component
- Layout
- Interaction
- Responsive
- Accessibility
- Internationalization
- Frontend validation

Backend, database production, API production, GPS engine, dan integrasi perangkat nyata belum menjadi scope.

## 3. Application

### Business

Application untuk kebutuhan bisnis/fleet management.

### Personal

Application untuk kebutuhan personal.

Keduanya tidak digabung sebagai satu navigation.

## 4. Prinsip

BINAGO harus:

- modern
- clean
- professional
- enterprise
- konsisten
- maintainable
- sederhana
- scalable

## 5. Bahasa

Dokumentasi: Bahasa Indonesia.

Source code: English.

UI: Indonesia dan English.

Default UI: Indonesia.
