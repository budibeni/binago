# BINAGO — UI Guidelines

## 1. Karakter Visual

BINAGO harus terlihat:

- modern
- clean
- professional
- enterprise
- konsisten

## 2. Layout

Gunakan struktur:

```text
Application Shell
├── Sidebar
├── Header
└── Content Area
```

Detail layout ditentukan pada Task Application Shell.

## 3. Header

Tidak ada Global Search pada Header.

## 4. Search

Search ditempatkan pada module yang membutuhkan.

## 5. Cards

Gunakan card reusable untuk summary, information, dan content grouping.

## 6. Tables

Gunakan DataTable Foundation.

Header kolom sticky ketika vertical scroll.

## 7. Forms

Gunakan label, validation, error state, loading state, dan feedback yang konsisten.

## 8. Responsive

Desktop, tablet, dan mobile harus diperhatikan.

## 9. Internationalization

UI mendukung Indonesia dan English.

Default Indonesia.
