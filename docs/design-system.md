# ADATRACK - Design System

## 1. Tujuan

Menyediakan visual language dan reusable component yang konsisten untuk ADATRACK.

## 2. Technology

```text
Tailwind CSS
Radix UI
```

Tidak menggunakan:

```text
Ant Design
MUI
Bootstrap
```

## 3. Design Tokens

Design token mencakup:

- color
- typography
- spacing
- radius
- shadow
- sizing
- transition

Detail token final ditetapkan dan dikembangkan pada Task 02.

## 4. Component Foundation

Component reusable meliputi kebutuhan seperti:

- Button
- Input
- Textarea
- Label
- Badge
- Avatar
- Card
- Alert
- Skeleton
- Spinner
- Dialog
- Dropdown
- Popover
- Tooltip

## 5. DataTable

DataTable adalah reusable foundation dan mendukung:

- pagination
- infinite scroll
- text search
- sorting
- optional column filter
- show/hide column
- export
- freeze column
- sticky header
- horizontal scroll

## 6. Aturan

Jangan membuat duplicate component jika foundation sudah tersedia.

Jangan membuat generic component hanya untuk satu feature.
